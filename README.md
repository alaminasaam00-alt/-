# DealRadar AI

DealRadar AI is a price-discovery MVP designed to help users compare products, track prices, and discover deals.

## MVP scope
- Product search over a curated catalog
- Price comparison across listed merchants
- Affiliate-ready outbound links
- Health-check endpoint
- Clear separation between product data and monetization links

## Important
This MVP does not claim live prices or affiliate revenue until verified data providers and approved affiliate programs are connected.

## Run locally
```bash
npm install
npm start
```

Open `http://localhost:3000`.
